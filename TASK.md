## Требования

### 1. Главная страница блога
- Отображает список всех статей пользователя

### 2. Inline редактирование (на своем nest)
- При наведении курсора на статью → рамка вокруг статьи
- Клик → активируется TipTap редактор ТОЛЬКО для этой статьи
- Автосохранение

### 3. Создание статей (3 способа)
- **A**: Кнопка "Создать статью"
- **Б**: Кликабельная область между заголовком и первой статьей
- **В**: Кликабельные области между статьями
